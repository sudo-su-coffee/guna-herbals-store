# External platform findings

- PostHog product analytics supports trends, funnels, retention, paths, stickiness, lifecycle insights, dashboards, alerts, API/MCP access, and uses the same events/persons/properties as its other tools: https://posthog.com/docs/product-analytics
- PostHog session replay links recordings with events, people, feature flags, console logs, network requests, errors, privacy masking, sampling, and retention controls: https://posthog.com/docs/session-replay
- PostHog self-hosting is open source and available through Docker Compose, but the official documentation says deployments are unsupported, require operator-managed infrastructure and upgrades, and recommends approximately 4 vCPU, 16 GB RAM, and more than 30 GB storage: https://posthog.com/docs/self-host
- Microsoft Clarity provides session recordings, heatmaps, ML insights, is free, has no stated traffic limits, stores data in Azure, and requires consent handling in the EEA/UK/Switzerland: https://learn.microsoft.com/en-us/clarity/faq
- Mixpanel pricing documentation lists funnels, retention, flows, cohorts, up to 1M events/month on its free plan, and session replays; it is a cloud product rather than a normal self-host migration target: https://mixpanel.com/pricing/
- Cloudinary is an API-first media platform with server uploads, browser uploads, transformations, CDN delivery, signed URLs, asset search, and Node.js SDK support. API secrets must remain server-side: https://cloudinary.com/documentation and https://cloudinary.com/documentation/upload_images
- Cloudflare R2 implements the S3 API with an R2 endpoint and region auto, making it a storage portability option, but it does not provide Cloudinary’s built-in image transformation and asset-management workflow: https://developers.cloudflare.com/r2/api/s3/api/
- Chatwoot is open source, self-hostable, supports website live chat, email, WhatsApp, social channels, APIs, help center, and customer data ownership. Its 2026 voice feature supports Twilio phone calls and WhatsApp Calling, subject to feature/account requirements: https://www.chatwoot.com/ and https://www.chatwoot.com/hc/user-guide/articles/1779863425-voice-calling-in-chatwoot
- Keycloak provides OpenID Connect, OAuth 2.0, SAML, SSO, identity brokering, social login, user federation, centralized roles/sessions, and self-hosted deployment options: https://www.keycloak.org/
- Better Auth is a TypeScript authentication and authorization framework with email/password, account/session management, rate limiting, social sign-on, organizations, 2FA, passkeys, and plugins: https://better-auth.com/docs/introduction
- SendTree.io presents itself as an email product with API and SMTP access, but the exact transactional email API contract should be confirmed before implementing provider-specific code: https://sendtree.io/
